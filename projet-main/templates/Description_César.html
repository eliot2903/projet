Chiffre de César

Le chiffre de César est l'une des techniques de chiffrement les plus anciennes et les plus simples. Il tire son nom de Jules César, qui l'utilisait pour communiquer secrètement avec ses généraux.

Son principe est très simple : chaque lettre du message est décalée d'un certain nombre de positions dans l'alphabet. Par exemple, avec un décalage de 3, la lettre A devient D, B devient E, Z devient C, etc.

Pour déchiffrer le message, il suffit d'appliquer le décalage inverse : on recule chaque lettre du même nombre de positions pour retrouver le texte original.
